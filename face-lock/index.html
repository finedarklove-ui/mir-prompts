2Train the Soul ID on the right photos

The training set decides everything. A face-only set gives you a perfect face on the wrong body.

학습 사진이 전부를 정해요. 얼굴 사진만 넣으면 얼굴은 맞는데 몸이 틀려요.

  • 5 face close-ups — front, 3/4 left, 3/4 right, soft light, neutral face.
    얼굴 클로즈업 5장 (정면·좌우 3/4)
  • 6 full-body shots — head to toe, so the model learns head size and leg length.
    전신 6장 — 머리 크기·다리 길이를 배우게
  • 4 upper-body shots showing the shoulders clearly wider than the head.
    상반신 4장 — 어깨가 머리보다 넓게
  • 3 expressions your character will actually act (mine: resolve, shout, pain).
    실제로 연기할 표정 3장
  • Real photos only. One drawing or 3D render in the set drags every result toward anime.
    사진풍만. 그림 한 장만 섞여도 애니로 끌려가요

3The lock: one Element per look

Make 1 face Element, then 1 Element for every outfit. Every shot starts from an Element — never from a loose photo.

얼굴 Element 1개 + 의상마다 Element 1개. 모든 컷은 Element에서 시작해요.

  • Check the Element's own photos first. If the outfit or body is off there, every shot inherits it.
    Element 사진부터 검수 — 거기서 틀리면 모든 컷이 따라 틀려요
  • Spell out outfit details in words (e.g. "covering the feet, completely intact"). Vague outfits drift.
    의상 디테일은 글로 정확히
  • Video models: Element only. Seedance may refuse face photos as references, and Elements hold better anyway.
    영상에서는 얼굴 사진 말고 Element만

4Image prompt (Nano Banana Pro)

Images 1–2 = face references, images 3–4 = body references. Telling the model which image controls what stops the face and body from mixing.

1~2번은 얼굴, 3~4번은 몸 참조. 어떤 사진이 무엇을 담당하는지 적어 줘야 안 섞여요.

5Video prompt (Seedance 2.5)

Put the film rule at the very top. Written as one line at the end, the model ignores it and the character stares into the lens.

시선 규칙은 맨 앞에. 끝에 한 줄로 쓰면 무시하고 카메라를 쳐다봐요.

Model Seedance 2.5Character Element only
Video template
FILM RULE: This is a feature film. [Name] NEVER looks at or toward the camera; no posing for the lens; eyes always locked on [target].
CHARACTER: [Name] <<<[your Element]>>> — [age], [3-5 face anchors], [hair], [body line]; body never changes.
ACTION: 0-3s [...]. 3-6s [...]. 6-10s [...].
PHYSICS: real-world physics; only the struck person reacts; nobody falls without a visible hit; no glow, no aura.
AUDIO: generate sound synced to the action; no metallic screeching.
NEGATIVE: looking at camera, posing, older face, body change, duplicated characters, subtitles, text, watermark.

6When the face still drifts

  • Looks older? Keep the face big (3/4 shot or closer), write "fashion magazine editorial", and use calm resolve instead of screams.
    나이 들어 보이면 — 얼굴 크게, 비명 대신 절제된 표정
  • A different person? When the face is under about 1/8 of the frame height, it stops being your character. Re-frame closer.
    다른 사람이 되면 — 얼굴이 화면 높이 1/8보다 작음. 더 가깝게
  • Wrong eye color? Name the color and add "not glowing, not gray" every time.
    눈 색이 새면 — 색 이름 + not glowing 매번
  • Two or more people? Soul is strongest on solo shots. For interaction, use Nano Banana Pro + Element.
    둘 이상 나오면 — Soul 말고 Nano Banana Pro + Element
  • Check every result. Crop the face and put it next to your reference before you move on.
    결과마다 얼굴만 잘라 기준 사진과 나란히 대조
